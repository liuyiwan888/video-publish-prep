# 四平台发布清单

`finalize.py` 会按这份规则把 `content.json` 派生成四套可发布文案 + `publish-kit.md`。发布按钮由人在各平台后台点。

---

## 1. 小红书（RedNote）

- 标题上限：**20 个汉字**（按需截断 + 表情补足）
- 正文上限：**1000 字**
- 封面：**3:4 必传**（`cover-3x4.png`）
- 话题：**真实话题实体**（从关键词里选 3-5 个），不要堆 # 标签
- 原创声明：默认关；用户明确表示原创才开

```
【标题】
<20 字以内的吸引点 + 情绪词 + 1-2 个 emoji>

【正文】
<description 全文，分段加 emoji，最后一段给一个 "📌 收藏夹点这" / "💬 评论区聊聊" 引导>

【话题】
点击平台搜索框选 "AI 提效" / "效率工具" / "副业" 等真实话题实体，不要手打 # 标签
```

---

## 2. 抖音（Douyin）

- 标题上限：**55 字**（前 15 字最关键）
- 正文上限：**1000 字**（实际前 2 行决定打开率）
- 封面：**3:4 必传**（`cover-3x4.png`），可加 4:3 横版备用
- 话题：3-5 个真实话题实体
- 原创声明：按 `content.json` 的 `is_original` 字段（默认 false）

```
【标题】
<前半句主钩子（≤15 字）+ " | " + 后半句价值点（≤40 字）>

【正文】
<description 全文 + 引导 "评论区告诉我你的情况"+ 1-2 个真实话题实体>

【话题】
搜索 "AI 实战" / "效率工具" 等真实话题，点击加入
```

---

## 3. Bilibili

- 标题上限：**80 字**
- 简介上限：**2000 字**
- 封面：**4:3 必传**（`cover-4x3.png`）
- 标签：≤ 10 个（系统会推荐，点选最相关的 5-8 个）
- 原创声明：按 `content.json` 的 `is_original`

```
【标题】
<主标题 + 副标点（用空格/破折号分隔，别用 | 太多）>

【简介】
<description 全文 + 时间戳章节（如果有 transcript 分段时间戳）+ 相关链接 + 关注引导>

【标签】
推荐：AI / 工具分享 / 效率 / 干货 / 教程
```

---

## 4. 微信视频号

- 短标题上限：**14 字**（独立短标题字段）
- 描述上限：**1000 字**
- 封面：**3:4 必传**（`cover-3x4.png`），可加 4:3 备选
- 话题：`# 真实话题` 形式（视频号支持 #）

```
【短标题】（填到"短标题"独立字段）
<14 字以内的强钩子，单独成句>

【描述】
<description 全文 + 2-3 个 # 真实话题 + 关注引导>

【话题】
格式必须是 # 话题，例如 #AI 提效 #效率工具
```


## 安全边界（重申）

- 不绕过登录、验证码、二维码
- 不导出 Cookie、不保存登录态
- 不点最终发布按钮
- 不擅自把视频 / 字幕 / 转写 / 封面发到任何非用户明确指定的服务（除 Agnes 出图这一步必须把 `cover.background` 的视觉 prompt 发到 agnes 端点）
